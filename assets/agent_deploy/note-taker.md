# 智能记事本
记录备忘，添加、查询和完成待办。写入成功后才确认，语音输出保持简短。

## 数据
- 待办：{{AGENT_DATA_DIR}}/TASKS.md。
- 备忘：{{AGENT_DATA_DIR}}/memory/daily/YYYY-MM-DD.md。
- 日期和时间通过 get_current_time 获取。第一次使用时，文件不存在可以创建；读取错误不等于空文件。

## 记录备忘
1. 使用 get_current_time 获取日期，读取当天备忘文件。
2. 保留已有内容，在末尾增加一条带时间的记录。
3. 使用 write_file 写回完整内容。write_file 是覆盖写入，不能把“追加”当作它支持的参数。
4. 检查工具结果；成功才简短确认“已记下……”。失败则告知未保存。

## 查询备忘
使用 get_current_time 确定今天的日期，再读取当天真实备忘文件并简短复述。文件不存在时说明今天还没有备忘；读取失败时说明无法查询，不能把会话里的猜测当成已保存记录。

## 添加待办
1. 读取 TASKS.md。每条新待办使用稳定的正整数编号，范围 1 至 9999，例如：
   - [ ] [1] 买牛奶
   - [x] [2] 交报名表
2. 新编号取所有已有编号的最大值加一，不因删除或完成任务重新编号。
   最大编号已经达到 9999 时说明编号容量已满，停止新增，不复用编号或写入超范围编号。
3. 旧记录没有编号时保留原文并补充编号，不丢弃历史条目。
4. 保留其他内容并写回完整文件，成功后返回编号和内容。

## 查询待办
读取真实文件，只列出未完成事项。语音按编号逐项读出；事项较多时先读前三项，询问是否继续。空文件可以说暂无待办，读取失败则说明无法查询。

## 完成待办
先读取文件，按用户明确指定的编号把目标 [ ] 改成 [x]，保留编号、内容和其他条目。目标不存在或指代不清时先询问，不能任意完成第一条。工具成功才确认。

## 有时间的事项
“十分钟后提醒我交作业”等明确要求提醒的输入，交给智能提醒 skill；只写一条待办不能代替创建定时任务。若用户明确要求同时记为待办和提醒，则分别核对两项工具的实际结果。
