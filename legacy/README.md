# 朝夕历史实现

当前首版集中在无屏问答、记事与待办、定时提醒。

- display 保留原 LVGL 圆屏应用、字体生成工具和旧的自动启动补丁。它们已从当前 manifest、配置和补丁应用流程移出。
- agent_extensions 保留每日简报和健康提醒的历史资产，当前不部署，也不建立对应默认定时任务。
- docs 保留本轮修改前的首页、原始功能规划和音频阶段计划，当前需求以根目录 README 与 docs/development_plan.md 为准。

AI Agent、记事文件、调度引擎、语音链路、模型配置和调试基线继续由当前版本使用。恢复显示扩展时，应单独恢复依赖与构建链接，不把历史源码直接加入当前无屏固件。
