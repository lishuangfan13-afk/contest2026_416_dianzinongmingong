# 朝夕演示视频脚本

视频以一次书桌旁的使用过程介绍朝夕：开机选择网络，语音提问，记录事项，按时提醒，再查看个性化资讯和飞书消息。计划时长约四分四十秒，使用实际设备、实际音频和专门准备的演示事项。

| 时间 | 画面与操作 | 讲述内容 |
| --- | --- | --- |
| 0:00 至 0:25 | 桌面、主机、喇叭和可选表情屏 | “朝夕是一台基于 openvela 的桌面 AI 生活管家，随口交代的事情，可以保存、执行并按时提醒。” |
| 0:25 至 0:55 | 开机询问，回答无线或有线，听到连接成功 | 说明板端本地选网和两种联网方式，展示无需触摸页面的操作 |
| 0:55 至 1:25 | 唤醒，提出一个简短问题，听见回答 | “板载麦克风采集声音，MiMo 处理语言，BES 负责业务和真实播放。” |
| 1:25 至 2:05 | 记下学生证，查询；添加两项待办，完成其中一项 | 展示实际保存、固定编号和精确完成 |
| 2:05 至 2:50 | 创建三十秒提醒，等待时介绍喝水周期，到期播报 | “任务保存在板上，调度器在约定时间主动投递。” |
| 2:50 至 3:30 | 播放今天或昨天资讯，展示来源与日期；演示发送飞书 | “朝夕按照兴趣整理资讯，语音即时听，飞书随后看。” |
| 3:30 至 4:05 | 架构图、本地选网、存储和音频模块画面 | 解释本地执行、MFCC／DTW、SSE 与分场景播放策略 |
| 4:05 至 4:40 | 两版对照、外观、源码与 AI 开发资料 | “从 9 月的圆屏原型，到现在的语音任务终端，我们把记录、提醒、个性化和消息联动整合到同一台设备。” |

录制时保留听见的原声，等待过程可用字幕或转场交代。画面中的任务使用演示专用内容；资讯展示对应日期，飞书展示实际收到的条目。需要更详细的技术讲述时，沿用 [技术报告](technical_report.md) 的系统结构；版本对照见 [功能演进](版本演进20260920至20261104.md)。
