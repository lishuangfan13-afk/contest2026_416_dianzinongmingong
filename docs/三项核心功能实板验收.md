# 三项核心功能实板验收

本页汇总朝夕的板上业务结果，并提供现场可照着执行的语音验收流程。当前演示使用电脑经 USB2UART 提供网络，BES 负责问答、数据保存、提醒调度和音频；默认启动时麦克风关闭。

## 当前验收状态

2026 年 11 月 2 日，发布记录对应的 BES 完成 **37 项业务检查和连续 10 次 PPP 启停**，全部通过。检查使用真实文字业务入口，覆盖模型问答、本地记事、待办、中文相对提醒、喝水控制、历史数据保留和退出清理，期间麦克风保持关闭。明早复核真人语音与听感；飞书实际发送待配置 App ID、App Secret 和固定收件目标，独立 Wi-Fi 继续联调。

当前发布固件已使用比赛指定的 **“你好，openvela”或“Hello，openvela”**，产品名称仍为朝夕。该版本已烧入并完成下表文字业务与启停检查；现场可直接执行下方晨间流程。镜像身份与结果见 [公开验收 JSON](bringup_logs/20261102_core_acceptance.json) 和 [发布 manifest](../firmware/headless_pc_link/nuttx_ap_headless.manifest.json)。

| 项目 | 实板结果 |
| --- | --- |
| 授时与真实问答 | UTC 校准确认；回答与本轮问题对应 |
| 备忘 | 新增后回读一致，旧内容保留；明确中文指令零模型调用 |
| 待办 | 两项新增取得不同编号，只完成指定项，查询与文件一致 |
| 单次提醒 | 中文相对时间本地创建、任务读回、到期投递并移除 |
| 取消提醒 | 只移除指定任务，其他任务保留，取消项未投递 |
| 喝水控制 | 开启、状态、重复开启和关闭走本地，重复设置保持同一任务，关闭后恢复原任务集合 |
| 连续启停 | 10 轮均完成就绪、对应问题回答、正常退出、串口与转发清理，无残留 Agent，无需 RESET |
| 数据与麦克风 | 核对既有记录和任务；本轮自动麦克风始终关闭 |

本轮本地记事约 0.349 秒，待办操作约 0.331～0.377 秒。这些是文字入口到业务完成的时间，语音体验再加上收句、ASR 和播报。语音输出现采用网络增量接收与 PCM 播放，交互规则见 [语音交互收尾](语音交互收尾.md)。

## 准备现场验收

接好供电、USB2UART、麦克风和此前已验证的喇叭接线。完全断电后按住 **POWER 约 2 秒**开机。先在仓库根目录启动电脑供网，保持该窗口运行：

```powershell
python tools/pc_link/launch.py --check-only
python tools/pc_link/launch.py --port COM3
```

看到 `PPP_UPLINK_READY` 后，在另一个 PowerShell 窗口检查状态与时间：

```powershell
python tools/pc_link/control.py --status
python tools/pc_link/control.py --time
python tools/pc_link/control.py --auto-status
python tools/pc_link/control.py --notes
python tools/pc_link/control.py --tasks
python tools/pc_link/control.py --reminders
```

查询结果的 `auto_voice` 对象应显示 `enabled=false`、`running=false`。核对镜像与 `wake_phrase` 中的新唤醒短语后，把本轮标记写成实际日期或简短代号，例如“晨间验收A”；先记下已有备忘和提醒，测试只新增本轮条目。

## 三分钟晨间真人验收

供网与版本检查提前完成，从主动启动监听开始计时。操作者靠近板上麦克风约 5～10 厘米，每句自然说一次，说完停顿，等喇叭回答结束再说下一句。

先启用唤醒匹配，然后在操作者准备好时启动采集：

```powershell
python tools/pc_link/control.py --cmd auto wake on
python tools/pc_link/control.py --cmd auto start
```

| 时间安排 | 操作者说的话或动作 | 现场核对 |
| --- | --- | --- |
| 0:00～0:35 | 等校准结束，说“你好，openvela，一加一等于几” | 正确唤醒，听到相关中文回答；记录说完到首声的时间和是否卡顿 |
| 0:35～1:10 | 说“帮我记一下晨间验收A，今天带学生证” | 听到保存结果，用下方回读命令找到对应原文与旧记录 |
| 1:10～2:05 | 说“三十秒后提醒我晨间验收A，起身喝水” | 听到创建确认，列表出现对应任务，约 30 秒后听到该事项 |
| 2:05～2:30 | 说“停止监听” | 自动语音结束，状态中 `enabled`、`running` 均为 `false` |
| 2:30～3:00 | 回读备忘、提醒和状态，记录本次结果 | 备忘已保存，到期任务已移除，监听已停止 |

会话内不必每句重复唤醒短语；如果中途安静超过 60 秒，下一句加上“你好，openvela”。状态显示正在识别、处理或播放时先等本轮结束。若某一步超过预留时间，记录所在阶段，先停止监听，再单独重测该项。

回读与停止命令均通过现有连接发送：

```powershell
python tools/pc_link/control.py --notes
python tools/pc_link/control.py --reminders
python tools/pc_link/control.py --auto-status
```

语音停止未完成时，用命令结束并再次查询：

```powershell
python tools/pc_link/control.py --cmd auto stop
python tools/pc_link/control.py --auto-status
```

最后正常结束供网：

```powershell
python tools/pc_link/launch.py --stop
```

等待正常退出提示后关闭窗口。本轮记录包括版本、识别出的需求、实际文件或任务回读、听到的播报、首声等待与连续性、最终监听状态和退出结果。有效说话与旁听由在场操作者确认。

## 待办与取消的补充检查

三分钟流程完成后，需要复核文字业务时执行以下步骤；编号使用本次实际返回值。

```powershell
python tools/pc_link/control.py --cmd --text todo add 晨间验收A交作业
python tools/pc_link/control.py --cmd --text todo add 晨间验收A带水杯
python tools/pc_link/control.py --tasks
python tools/pc_link/control.py --cmd --text todo done 1
python tools/pc_link/control.py --tasks
```

将 `1` 替换为第一项的真实编号。核对第一项为 `[x]`、第二项仍为 `[ ]`，原有条目和编号保持。

```powershell
python tools/pc_link/control.py --cmd --text remind in 120 晨间验收A取消对照
python tools/pc_link/control.py --reminders
python tools/pc_link/control.py --cmd --text remind cancel a123b456
python tools/pc_link/control.py --reminders
```

将 `a123b456` 替换为本轮真实任务 ID。核对只移除目标，原有提醒保持；观察到原定时间后确认目标未投递。

## 文件与结果保存

| 内容 | 板端位置 |
| --- | --- |
| 当天备忘 | `/emmc/zhaoxi/memory/daily/YYYY-MM-DD.md` |
| 带编号待办 | `/emmc/zhaoxi/TASKS.md` |
| 提醒列表 | `/emmc/zhaoxi/cron.json` |
| 长期记忆 | `/emmc/zhaoxi/memory/MEMORY.md` |

备忘按板端授时后的北京时间归档。一次正常退出并重新启动供网后，再读取本轮记录，核对保存结果。测试期间保留用户历史数据；原始语音和串口记录由操作者私下保存，比赛材料使用整理后的结果。
