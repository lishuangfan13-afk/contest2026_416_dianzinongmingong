# 朝夕核心功能使用说明

朝夕围绕三个日常动作设计：有问题就问，想到事情就记，需要按时完成的事项交给提醒。当前版本使用 BES2800BP、板载麦克风、两线喇叭和 eMMC，电脑经 USB2UART 提供网络与文字操作入口。

## 先启动网络和助手

完成 [固件与资产安装](BES固件构建与验收.md) 后，在仓库根目录运行：

```powershell
python tools/pc_link/launch.py --check-only
python tools/pc_link/launch.py --port COM3
```

启动程序确认旧助手退出，用电脑 UTC 时间校准板子，然后建立 PPP 并启动业务。看到 `PPP_UPLINK_READY` 后，另开一个 PowerShell 窗口操作。保持启动窗口运行，后续命令通过控制通道送往板子。

```powershell
python tools/pc_link/control.py --status
python tools/pc_link/control.py --time
```

日常演示采用文字输入和喇叭播报；`--text` 可切换为文字回复。仅供网启动保持麦克风关闭。连续语音入口见本页末尾。

## 一、问答

```powershell
python tools/pc_link/control.py --cmd ask 用一句话解释DMA
```

板上的 Agent 调用 MiMo 整理回答，再交给语音输出。问题可以直接输入文字，也可以来自麦克风识别结果。回答默认保持简短，适合喇叭播报。

需要查看文字时，在业务参数前增加 `--text`：

```powershell
python tools/pc_link/control.py --cmd --text ask 什么是待办清单
```

控制命令先返回提交结果，默认语音模式由喇叭播放答案。`--text` 主要用于开发诊断，文字答案写入本机会话记录中的板端输出；启动窗口显示网络和语音阶段状态。网络或服务错误会通过应用状态反馈。

## 二、记事与待办

### 记录当天备忘

```powershell
python tools/pc_link/control.py --cmd note 明天带学生证
python tools/pc_link/control.py --notes
```

明确的 `note` 命令由板端本地模块直接追加保存，完成 `fsync` 后回读核对，不需要等待模型生成文件操作。日期按北京时间划分，备忘保存在 `/emmc/zhaoxi/memory/daily/YYYY-MM-DD.md`。`--notes` 直接回读当天文件，也可以运行 `--cmd --text note list` 查看。

### 添加与完成待办

```powershell
python tools/pc_link/control.py --cmd --text todo add 交作业
python tools/pc_link/control.py --cmd --text todo add 带水杯
python tools/pc_link/control.py --tasks
```

每条待办有固定编号：

```markdown
- [ ] [1] 交作业
- [ ] [2] 带水杯
```

按实际编号完成一项：

```powershell
python tools/pc_link/control.py --cmd --text todo done 1
python tools/pc_link/control.py --tasks
```

目标项的 `[ ]` 变为 `[x]`，另一项及已有历史继续保留。`--tasks` 回读完整文件；`--cmd --text todo list` 只列未完成项。

这些待办命令由 `todo_store.c` 在本地执行，不调用模型。编号递增、范围 1～9999，单文件上限 64 KiB；完成操作支持重复调用，已完成项会返回已有状态。遇到重复编号或旧无编号格式时，先整理文件，再继续修改。

在板端 NSH 中还可以直接运行 `zhaoxi --text note ...` 与 `zhaoxi --text todo ...`，即使 Agent 未启动也能管理这些记录；备忘需要先校准板上日期。明确的中文前缀可直达同一本地模块，例如“帮我记一下明天带学生证”“添加待办交作业”“完成待办编号3”。其他自由表达由 Agent 结合 Skill 处理，业务完成确认对应本轮实际工具结果。句式与边界见 [本地中文指令](本地中文指令.md)，文件保存方式见 [本地记事](本地记事.md)。

## 三、定时提醒

### 快速创建

本机相对时间入口适合现场演示：

```powershell
python tools/pc_link/control.py --cmd remind in 30 喝水
python tools/pc_link/control.py --reminders
```

提醒保存到 `/emmc/zhaoxi/cron.json`，创建结果包含八位任务编号和到期时间。时间到达后，板端调度器将事项送往语音通道。网络或语音合成不可用时，板子输出事项文字并播放本机提示音。

相对时间范围是 1～31536000 秒的整数。`--text remind in ...` 创建的提醒到期发送文字，默认入口创建语音提醒。

### 自然语言时间

```powershell
python tools/pc_link/control.py --cmd remind 三十秒后提醒我喝水
```

这类明确的相对时间表达由本地解析器直接创建并读回同编号任务。支持阿拉伯数字，以及 1～99 的中文整数和“两”，单位为秒、分钟或小时；例如“三十秒后提醒我喝水”“二十分钟后提醒我取快递”。复杂日期与周期表达继续交给 Agent。当前支持一次性与固定间隔提醒；句式规则见 [本地中文指令](本地中文指令.md)。

### 查询与取消

```powershell
python tools/pc_link/control.py --reminders
python tools/pc_link/control.py --cmd remind cancel a123b456
```

把示例编号替换为真实任务 ID。取消后重新查询，确认目标已移除。已到期的一次性任务在成功投递后移出调度列表；队列拥堵时保留重试。

主机入口每次启动时校准 UTC，提醒保存 UTC epoch，面向用户显示北京时间。固定间隔提醒恢复时跳过已经错过的周期，安排未来一次；冷启动尚未授时时先等待校时。

## 生活提醒与状态扩展

### 喝水提醒

```powershell
python tools/pc_link/control.py --cmd drink start
python tools/pc_link/control.py --cmd drink status
python tools/pc_link/control.py --cmd drink stop
```

默认每 60 分钟提醒一次；`drink start 30` 可改为每半小时。此功能使用独立的本机周期任务，关闭时只移除喝水任务，保留用户其他提醒。间隔范围与恢复方式见 [喝水提醒](喝水提醒.md)。

### 飞书固定目标通知

飞书通知默认关闭。填好设备上的应用凭据和固定收件目标后，可主动发送一条测试消息：

```powershell
python tools/pc_link/control.py --cmd notify status
python tools/pc_link/control.py --cmd notify test demo-001
```

设备使用应用身份向预设目标发送，返回服务接受结果；不同通知使用不同事件编号。配置方法见 [飞书通知接口](飞书通知接口.md)。本地提醒与通知各自保留结果，飞书模块由明确命令调用。

### EasyMatrix 颜文字屏

BES 与 EasyMatrix 分别通过自己的 USB 串口连接电脑。原供网窗口管理 BES 的 FTDI，显示桥管理屏端 CH343，将空闲、聆听、思考、播报、成功、错误、休眠与时钟映射为固定表情。

```powershell
python tools/display_link.py --port COM4 --show listening
python tools/display_link.py
```

`COM4` 按实际 CH343 端口修改。先运行第一条观察独立表情，再用第二条跟随朝夕会话。屏端需要配套 `zhaoxi.display` 固件，使用说明见 [颜文字屏](颜文字屏使用.md)，源码位于 [extension/EasyMatrix](../extension/EasyMatrix/README_zh-cn.md)。

## 数据保存与语音开关

| 内容 | 板端位置 |
| --- | --- |
| 当天备忘 | `/emmc/zhaoxi/memory/daily/YYYY-MM-DD.md` |
| 带编号待办 | `/emmc/zhaoxi/TASKS.md` |
| 提醒列表 | `/emmc/zhaoxi/cron.json` |
| 人格与运行配置 | `/emmc/zhaoxi/config/` |
| 业务 Skill | `/emmc/zhaoxi/skills/` |

资产部署默认保留已有记忆与提醒，待办文件由业务操作维护。记事、待办与提醒的完成确认依据实际保存结果；存储错误会返回未完成，便于用户重试。

需要体验自动语音时，结束已有会话，再主动选择 [开始自动语音.cmd](../tools/pc_link/开始自动语音.cmd)。先说“朝夕”“你好朝夕”或“小朝夕”，可以把需求接在同一句；会话内无需每句重复名称，空闲 60 秒后重新等待唤醒。此入口使用 VAD、云端 ASR 和板端前缀匹配，等待唤醒时仍进行语音识别。规则见 [ASR 唤醒短语](ASR唤醒短语.md)。

当前版本以电脑供网为主，连续语音仍待现场真人验收。语音识别与播报期间暂停收音，听到就绪提示后再说下一句。默认联网模式、显式切换 Wi-Fi 和退出行为见 [联网方式配置](联网方式配置.md)。

结束会话使用：

```powershell
python tools/pc_link/launch.py --stop
```

等待正常结束提示后关闭窗口。完整硬件、构建和检查说明见 [构建与验收](BES固件构建与验收.md)。
