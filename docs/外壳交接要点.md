# 朝夕实物外壳交接

主机使用 BES 开发板、现有喇叭和外置天线，提供问答、记事待办、定时提醒。EasyMatrix 沿用现有外壳，作为独立的颜文字状态屏摆放；BES 壳体先围绕主板和音频部件制作。队友会拿到实际部件，所有孔位、尺寸和安装间隙以实物测量为准。

## 可以立即开展

- 固定开发板与现有喇叭，先做能够重复打开的壳体，保留接线、维修和换固件的空间。
- 按当前实际供电与 USB2UART 数据线接法预留出线孔。电脑联网方案需要数据通道，不能只保留供电孔。
- RESET、POWER 等操作位置保持可触达；开发和验收阶段可能需要按键恢复。
- 金色 SMA 天线座保持可装卸，外置胶棒天线的转动和折弯空间以到货实物为准。
- 麦克风拾音与喇叭出音位置保留开口，避免用壳体或固定胶挡住拾音通道。
- 喇叭线、USB 线和天线安装不要对焊点施加持续拉力，合盖前确认没有夹线。
