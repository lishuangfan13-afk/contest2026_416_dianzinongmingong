# 朝夕实物、软件与比赛材料交付

交付内容包括 BES2800BP 无屏助手、现有喇叭与接线、电脑供网工具、AP 固件、业务资产和使用文档。队友拿到实物后测量并制作可拆外壳，比赛材料按 11 月 4 日的提交安排整理。

| 类别 | 内容 |
| --- | --- |
| 硬件 | 开发板、现有喇叭、外置天线、USB2UART 数据线、原供电线 |
| 软件 | 当前 AP BIN 与 manifest、`tools/pc_link`、业务资产模板 |
| 使用资料 | [作品首页](../README.md)、[核心功能](无屏核心功能.md)、[构建与安装](BES固件构建与验收.md) |
| 机械资料 | 当前接线照片、实物孔位与尺寸、[外壳交接要点](外壳交接要点.md) |

交接前拍下当前跳帽与喇叭接法，板子随现有连接一起交给队友。外壳按实物预留 USB2UART、供电、RESET、POWER 和可拆天线空间；麦克风与喇叭留出通声孔，固定结构避开焊点和线材。壳体先做成可重复打开的形式，方便后续维护。

## 演示电脑准备

当前工具使用 Windows、Python 3、pyserial 和 Ubuntu-22.04 WSL。WSL 需要 Python 3、`pppd`、`ip`、`iptables`、PPP／TUN 设备，以及能配置网络转发的 root 环境。FTDI 驱动应能识别板子的 USB2UART。

```powershell
python -m pip install pyserial==3.5
python tools/pc_link/launch.py --check-only
```

预检通过后，保留电脑的正常互联网连接，使用 [仅共享网络.cmd](../tools/pc_link/仅共享网络.cmd) 启动。它先用电脑 UTC 时间校准板子，再建立 PPP。演示期间保留窗口，用 [control.py](../tools/pc_link/control.py) 发送业务命令，避免另开串口程序占用连接。

结束用 [停止朝夕语音.cmd](../tools/pc_link/停止朝夕语音.cmd) 或 `python tools/pc_link/launch.py --stop`，等窗口确认正常结束。自动语音只在在场使用者主动选择对应入口后开启。

## 现场演示顺序

| 步骤 | 操作 | 查看结果 |
| --- | --- | --- |
| 1. 启动与授时 | 恢复供电，运行正式启动入口，再执行 `control.py --time` | 时间回执与现场日期一致，控制通道就绪 |
| 2. 问答 | `control.py --cmd ask 用一句话介绍自己` | 喇叭或文字返回对应回答 |
| 3. 备忘 | 记录一条带“交付演示”标记的内容，再执行 `--notes` | 当天文件含新增记录与既有内容 |
| 4. 待办 | 添加两项，执行 `--tasks`，只完成其中一个编号 | 指定项变为 `[x]`，另一项保留 |
| 5. 提醒 | 创建 30 秒后的提醒，再另建一项并取消 | 第一项到期投递，取消项从列表移除 |
| 6. 保存与合盖 | 正常结束，重新启动后回读记录；合盖后再听一次播放 | 记录保留，按键、接口和声音通路可用 |

完整命令可以从 [核心功能说明](无屏核心功能.md) 复制。当前演示主线是电脑供网、文字业务输入与语音播报；连续自动语音与独立 Wi-Fi 的联调状态由交接者说明。

## 软件快照与配置

AP 镜像和 manifest 放在 [firmware/headless_pc_link](../firmware/headless_pc_link/)，以 manifest 的大小、SHA256 与烧录地址核对版本。复制包由 `tools/prepare_delivery_bundle.py` 生成，包含 `BUNDLE.json`、`SHA256SUMS` 和 `verify_bundle.py`。在复制包根目录执行：

```powershell
python verify_bundle.py
python tools/pc_link/launch.py --check-only
```

快照提供作品文件；演示电脑仍需先安装上述 Python、WSL 与驱动环境。构建或重刷 AP 时另准备完整 openvela 工作区、匹配 BSP 库和厂商下载工具。

板端的 API key、Wi-Fi 凭据和真实用户数据留在 `/emmc/zhaoxi`。业务资产是干净模板，部署时保留已有 MEMORY 和 cron；当前待办与每日备忘继续由业务维护。换新板时，按 [构建与安装](BES固件构建与验收.md) 部署并单独配置服务账号。
