# 11 月 2 日夜间工作与伙伴交接

本页保留当晚修复与检查记录。首次接手项目请先读 [项目完整交接](项目完整交接.md)，了解比赛、硬件、软件、运行和全部待办。

这份说明记录 11 月 1 日晚至 11 月 2 日早完成的工作，供接手实物、制作外壳和准备演示的伙伴使用。**软件与固件已提交，BES 和 EasyMatrix 均已完成构建、烧录及相应检查。接下来优先完成外壳和现场语音体验。**

当前演示方案是 **BES 主机 + 喇叭 + 电脑供网**，EasyMatrix 像素钟作为可选表情屏。电脑通过 USB2UART 转发网络，BES 自己执行录音、MiMo 请求、本地业务和播放。原圆形 AMOLED 屏仍全黑，当前程序以无屏方式运行。

## 伙伴先看这四件事

1. **拿到板子先保留现有跳帽、喇叭和天线接法。** 板内已有最新固件，测尺寸、做外壳不需要重新烧录或清空存储。
2. **在新电脑上演示，要先准备供网环境。** 只插供电线可以开机；联网演示还要连接 USB2UART，并运行仓库内的电脑供网工具。
3. **本轮实板通过的是文字业务与启停检查。** 最终版的连续真人语音、音量、卡顿和说完到回答的等待时间，需要拿到实物后听一轮；流程已写好。
4. **先做可拆外壳。** 留出麦克风和喇叭声孔、两根 USB、POWER／RESET 操作空间和天线转动空间。尺寸与孔位以手上的实物为准。

当晚开发在个人 fork 的 `bes-single-board-baseline-20261030` 分支完成，通过 [PR #12](https://github.com/open-vela/contest2026_416_dianzinongmingong/pull/12) 集成。当前正式交付入口为 [专属仓 dev-ai-contest-2026 分支](https://github.com/open-vela/contest2026_416_dianzinongmingong/tree/dev-ai-contest-2026)，最新说明见 [项目完整交接](项目完整交接.md)。

## 换电脑后的最短启动流程

以下命令均在仓库根目录运行。Windows 需有 Python 3、FTDI 驱动和 Ubuntu-22.04 WSL；WSL 中准备 Python 3、`pppd`、`ip`、`iptables`、PPP／TUN 设备和 root 网络转发权限。依赖说明见 [电脑网络共享](电脑网络共享.md)。

```powershell
python -m pip install pyserial==3.5
python tools/pc_link/launch.py --check-only
```

接好原供电线和 **USB2UART** 数据线。从完全断电开始时，按住板上 **POWER 约 2 秒**开机。串口号以新电脑的设备管理器为准，下面的 COM3 是原电脑的端口示例。

```powershell
python tools/pc_link/launch.py --port COM3
```

保留这个窗口，看到 `PPP_UPLINK_READY` 后，在另一个窗口检查：

```powershell
python tools/pc_link/control.py --time
python tools/pc_link/control.py --auto-status
python tools/pc_link/control.py --notes
python tools/pc_link/control.py --tasks
python tools/pc_link/control.py --reminders
```

默认自动语音状态应为 `enabled=false`、`running=false`。先用文字核对业务可达，再按 [现场语音验收流程](三项核心功能实板验收.md) 主动开启麦克风。若暂时只做外壳，保留关闭状态即可。

```powershell
python tools/pc_link/control.py --cmd ask 用一句话介绍自己
```

可选像素屏独立连接电脑，使用 CH343 串口；在另一个窗口启动：

```powershell
python tools/display_link.py
```

结束体验时，先停止自动语音并核对状态，再正常结束供网：

```powershell
python tools/pc_link/control.py --cmd auto stop
python tools/pc_link/control.py --auto-status
python tools/pc_link/launch.py --stop
```

等待正常退出提示后关闭窗口。串口由供网工具统一管理；后续文字操作继续使用 `control.py`，保持同一连接。
