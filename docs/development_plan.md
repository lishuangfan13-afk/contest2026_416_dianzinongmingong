# 朝夕交付与验收计划

更新：2026 年 11 月 2 日。11 月 4 日提交比赛 PR 和答辩材料前，工作重点是把现有功能整理成可重复演示、可交接的作品。当前主方案是 **BES 执行业务和音频，电脑经 USB2UART 提供网络，EasyMatrix 作为可选的状态显示终端**。

## 已完成的功能

| 功能 | 当前实现 | 已完成的实板检查 |
| --- | --- | --- |
| 问答 | 板端 Agent 调用 MiMo，回答经增量 TTS 和喇叭输出 | 真实文字问题取得对应模型回答 |
| 记事与待办 | 明确命令和有限中文句式直接执行本地保存、查询与按编号完成 | 新记录回读、指定待办修改、历史内容保留 |
| 定时提醒 | 本地相对时间创建、查询、取消和到期调度；复杂时间交给 Agent | 中文“三十秒后提醒我”、到期投递、单项取消与其他任务保留 |
| 喝水提醒 | 用户主动开启、查询和关闭；默认每 60 分钟一次 | 零模型调用、同设置重复开启保持同一任务、关闭后恢复原任务集合 |
| 状态显示 | 电脑桥接 EasyMatrix，以颜文字显示聆听、思考、播报等状态 | 七种表情、回执、帧更新、到期恢复时钟，原有 23 项屏端配置保留 |
| 启动与退出 | 电脑入口校准 UTC、建立 PPP、启动助手并在结束时释放串口 | 37 项业务检查通过，连续 10 次启停与对应问答通过，均无需 RESET |

明确中文记事、待办、相对提醒和喝水指令直接进入本地模块，省去文本模型往返；其他表达继续使用 Agent。语音输出已采用网络增量接收和有界 PCM 队列。使用方法见 [核心功能](无屏核心功能.md)，公开实板结果见 [11 月 2 日验收记录](bringup_logs/20261102_core_acceptance.json)。

## 交付顺序

1. **完成晨间真人验收。** 按 [三分钟验收流程](三项核心功能实板验收.md#三分钟晨间真人验收)，检查官方唤醒短语、问答、记事、30 秒提醒和停止监听，记录可听见的内容与实际等待时间。
2. **固定演示版本。** 以 [BES manifest](../firmware/headless_pc_link/nuttx_ap_headless.manifest.json) 和 [屏端 manifest](../firmware/easymatrix/EasyMatrix.ino.manifest.json) 对齐镜像、源码与安装步骤；演示前重新运行文字业务与退出检查。
3. **完成外壳交接。** 队友按实物测量，保留 POWER、RESET、两个 USB 接口、天线安装位置、麦克风声孔和喇叭出声孔。合盖后复听提示音与语音，按 [交付清单](交付核对清单.md) 逐项核对。
4. **录制比赛演示。** 展示一次真实问答、一条备忘及回读、一条到期提醒，再补充喝水控制与颜文字状态；画面交代电脑供网方式，素材使用同一发布版本。
5. **整理并提交材料。** 核对首页、使用说明、固件、补丁、构建方法、演示视频与 PR 链接；API 凭据、Wi-Fi 密码、原始录音和本机运行记录留在私有环境。

真人语音复核、飞书实账号配置和独立 Wi-Fi 的当前安排，统一见 [验收状态](三项核心功能实板验收.md#当前验收状态)。交付主线继续使用已经打通的电脑供网方式。

## 数据和维护约定

- 备忘保存在 `/emmc/zhaoxi/memory/daily/YYYY-MM-DD.md`，待办保存在 `/emmc/zhaoxi/TASKS.md`，提醒保存在 `/emmc/zhaoxi/cron.json`。
- 开机联网时用电脑 UTC 校准板子，用户日期按北京时间显示；冷启动按住 POWER 约 2 秒。
- 资产更新保留已有记忆和提醒，验收使用独立标记并核对原记录。完成待办只修改指定编号，取消提醒只移除对应任务。
- 默认启动只提供网络，麦克风保持关闭；操作者主动开启自动语音，结束后确认监听线程退出。
- 每次完整构建和烧录的版本以 manifest 为准，历史测量保留各自镜像身份。
