# 自动语音的交互与停止规则

朝夕采用半双工语音：收一句、识别与处理、回答，再接下一句。电脑提供网络，VAD 收句、本地业务路由、Agent 和 PCM 播放都在 BES 上执行。默认联网入口保持麦克风关闭，使用者主动启动自动语音后才开始收音。

## 启动和唤醒

先按 [电脑供网说明](../tools/pc_link/README_zh-cn.md) 建立连接，看到 `PPP_UPLINK_READY` 后，在另一个 PowerShell 窗口操作：

```powershell
python tools/pc_link/control.py --auto-status
python tools/pc_link/control.py --cmd auto wake on
python tools/pc_link/control.py --cmd auto start
```

启动后先校准约一秒，等就绪提示再开口。当前发布版本使用“你好，openvela”或“Hello，openvela”作为唤醒短语，产品名称仍是朝夕。可以把短语和需求放在同一句，也可以唤醒后再说需求；会话内不用逐句重复，安静 60 秒后回到等待唤醒。版本核对与现场体验见 [实板验收](三项核心功能实板验收.md)，短语匹配规则见 [ASR 唤醒短语](ASR唤醒短语.md)。

唤醒采用“VAD 检测声音 → 云端 ASR 识别 → 板端匹配句首短语”的流程。等待唤醒时仍进行收句和云端识别；`auto wake on` 只设置匹配规则，`auto start` 才开启自动采集。

## 一句话怎样结束

收句依据音量和时间：连续约 60 ms 超过环境阈值后视为开始说话，保留此前最多 300 ms 的声音。开始后连续约 **1.2 秒**低于人声阈值就封句；较短的换气通常保留在同一句，至少 240 ms 的有效发声才提交。

封句后的短低音表示“本句已收取，正在处理”。随后暂停麦克风，依次完成 ASR、业务处理和回答。此时继续说的话不会排队；回答播完、收音恢复后，再说下一句。

录音同时受 12 秒上限和实际缓冲容量限制。超长时丢弃本轮，等待说话者停顿后再接下一句，避免把半截记事或提醒送入业务。收到错误提示后，分成较短的完整指令重说。

## 识别、处理和出声

ASR 在本地封句后整句上传。识别得到明确的记事、待办、相对提醒或喝水控制句式时，板端直接保存或调度，不请求文本模型；其他问题由 Agent 结合当前问题和会话上下文回答。句式见 [本地中文指令](本地中文指令.md)。

TTS 使用 **SSE 增量接收音频，解码后送入有界 PCM 队列，网络接收与 DMA 播放同时推进**。首播保留约 640 ms 的预缓冲，较短的音频在接收结束时提交。回答默认简短，使用者要求展开时再增加内容。传输与历史测量见 [语音响应优化](语音响应优化.md)。

`--auto-status` 直接返回 `auto_voice` 对象中的收音、唤醒与处理状态。使用专用自动语音启动入口时，窗口也会显示收音、识别、等待回答、语音合成和实际播放等阶段。判断一次等待时，分别记录说完到封句、ASR、业务处理、TTS 首声和播放结束，便于区分收句停顿、模型请求和网络接收的耗时。

## 下一句、提醒和异常恢复

- 回答处理和播放期间暂停收音，播报期间不支持插话打断。
- 提醒播报需要独占音频设备，可能中断当前收音。等就绪提示恢复后，完整重说本句。
- 初次启动校准环境噪声，后续保留并缓慢更新基线；提示音前释放采集设备，恢复时短暂跳过残响。
- 每轮使用独立编号隔离迟到回复。停止或取消的轮次不再播报，会话历史继续保存前文。
- 请求失败时给出本地提示并恢复；等待最终回答超时会停止自动监听，操作者检查状态后再主动启动。

## 停止监听和结束使用

在已唤醒的会话中说“停止监听”，或使用控制入口：

```powershell
python tools/pc_link/control.py --cmd auto stop
python tools/pc_link/control.py --auto-status
```

停止会先关闭继续收音的开关，再等待当前处理和工作线程退出。状态中 `enabled=false`、`running=false` 表示自动语音已结束；`enabled=false`、`running=true` 表示仍在收尾。

只停止监听会保留电脑供网。结束整个会话时运行：

```powershell
python tools/pc_link/launch.py --stop
```

等待正常结束提示后关闭窗口，程序会等待板端退出、串口释放和电脑转发规则清理。当前验收结果及现场安排见 [三项核心功能实板验收](三项核心功能实板验收.md#当前验收状态)。
