# 喝水提醒

朝夕提供独立的本机喝水提醒，使用者开启后按固定间隔提示，默认间隔 60 分钟。设置保存在板上，关闭时只移除该功能自己的任务，其他提醒继续保留。

## 用语音开启、查询和关闭

主动开启自动语音后，可以直接说“朝夕，开启喝水提醒”。听到确认后，在当前会话中说“查询喝水提醒”或“关闭喝水提醒”即可，不需要每次由电脑发送命令。电脑仍负责供网。

| 明确说法 | 本地操作 |
| --- | --- |
| 开启喝水提醒／开始喝水提醒 | 开启默认每 60 分钟一次的任务 |
| 关闭喝水提醒 | 只关闭本功能自己的任务 |
| 查询喝水提醒／喝水提醒状态 | 读取实际开启状态与间隔 |

这些整句允许“请”“帮我”“请帮我”前缀，以及句末常见标点。例如“请帮我开启喝水提醒”。本地路由不调用文本模型，操作结果沿原来的语音回复流程播报。自定义间隔、问句和其他说法继续使用原 Agent 流程；本机快捷句式保持上述五种。规则也见 [本地中文指令](本地中文指令.md)。

## 开启、查询和关闭

```powershell
python tools/pc_link/control.py --cmd drink start
python tools/pc_link/control.py --cmd drink status
python tools/pc_link/control.py --cmd drink stop
```

自定义半小时间隔：`python tools/pc_link/control.py --cmd drink start 30`。间隔范围为 1～1440 分钟；重复开启同一设置沿用已有任务，更换间隔时先关闭再开启。

到期内容为“该喝水了，休息一下再继续。”，使用与其他提醒相同的语音和本机提示音流程。设备时钟由电脑供网启动入口校准。更新或断电后，周期任务按下一个未来周期继续。

调试时在 `--cmd` 后加入 `--text`，将提醒投递到文字通道：

```powershell
python tools/pc_link/control.py --cmd --text drink start 1
python tools/pc_link/control.py --cmd --text drink status
python tools/pc_link/control.py --cmd --text drink stop
```

## 实现与检查

`app/zhaoxi/drink.c` 复用真实 cron 持久化调度器，以独立任务归属保留用户其他提醒。核心 `zhaoxi_drink_execute()` 只执行存储并返回结果；明确中文指令交给 Agent 原有回复分发，命令入口则保留原来的 CLI／voice 输出。

同设置重复开启沿用原任务，开启和关闭后核对实际任务列表；并发操作由互斥锁串行处理。时钟、保存或读回失败会返回未完成，使用者可先查询当前状态，再决定是否重试。关闭操作只处理 `zhaoxi_drink` 所属的普通周期任务。

`tests/headless/check_drink.py` 编译实际模块、调度器和消息总线，覆盖参数边界、默认关闭、重复开启、任务归属、时钟与存储错误、八线程开启、读回失败和命令语音输出。`check_local_intent.py` 进一步通过实际 Agent 工作线程验证中文指令、零模型调用、回复轮次、取消与失败恢复。

```bash
python3 tests/headless/check_drink.py --sdk /path/to/openvela/packages/ai_agent --cjson /path/to/openvela/apps/netutils/cjson/cJSON
python3 tests/headless/check_local_intent.py --sdk /path/to/openvela/packages/ai_agent
```
